## When to write an ADR

Писать, если есть:

- цена класса задач (иначе следующий агент предложит то же);
- проверяемая причина со ссылкой на path / секцию;
- вердикт, который владелец принял.

Не писать: вкус, «X плохо», то что видно из одного-двух файлов кода, идея агента без подтверждения владельца.

## Override

- «Сделай X» / «попробуй ODYSSEA» **не** значит передумал.
- Конфликт с `do-not` → показать ADR (id, do-not, цена, Reopen), **не кодить**.
- Override только после явного `supersede ADR-N` в этом сеансе → сделать правку → новый ADR со status `superseded` у старого.

## Verification rules

1. Каждое утверждение ADR — цитата улики с path и названием секции. Нет ссылки → строку не писать.
2. Вердикт, не обобщение. «Не меняем без X» — можно; «лучше нет», «точнее не существует» — нельзя.
3. Цифры и константы не копировать: ссылка на символ (`CMEMS_SEARCH_RADIUS` в `scripts/update_beaches.py`) или на секцию улики.
4. Относительные ссылки проверять от каталога файла (`docs/mar-qa.md` → `adr/0001-…`).
5. Разделять вердикт прогона и постоянную политику: в ADR — только политика; дату прогона оставлять в улике.

На ADR, планы и отчёты:

6. Утверждение о поведении кода — со ссылкой на файл и строки, проверенное чтением файла в этом сеансе. Память о прошлом чтении не считается.
7. Утверждение о внешнем API — подтверждено живым запросом или страницей манула, ответ или цитата сохранены в улику.
8. Цитируя улику, цитировать её единицы измерения. Не подставлять единицы из соседней строки той же секции.
9. Методику одной величины не копировать на другую и не путать механизм показа. `PRIMARY_ORDER` и `pick_primary` выбирают только суточное `beach.t`. Волны и ветер туда не входят. §Шаг 2 в mar-qa — TEMP и файлы `IR_TS_MO_*`; для WAV нужны другие переменные и проверка, что у платформы они есть.

## Не решено

Молчание ADR ≠ запрет. Свободно (или спросить владельца):

- выбор UI-подхода и вёрстки в `index.html`;
- текст и копирайт на испанском;
- состав `data/*.json` (кроме политики CMEMS выше);
- порядок `PRIMARY_ORDER`;
- добавление источников, не связанных с CMEMS.

В зоне триггера молчания нет — там ADR-0001.
